# DX-OS v0.4.0 — Confirmed business actions and tenant administration

## Changes

- Existing seven user/role CRUD permissions now protect real organization account and role APIs and the Settings administration UI. No automatic grants; no change to demo permission assignments. Tenant membership removal preserves global identities and other organizations. Role grant changes require role:assign and the actor's permission ceiling; own role editing and deletion/deactivation of assigned roles are blocked.
- Workflow TASK creates an actual task. ACTION renews a selected contract or activates an eligible document after human confirmation. Business writes reuse domain services; effect, step and audit commit atomically. Failed actions expose an explicit retry; committed effects are not repeated. The UI selects definition, document and renewal date rather than asking for UUIDs.
- AI proposes an editable task draft; only a separate explicit confirmation creates the task under current permissions. Drafts are actor/tenant bound, expire after 30 minutes, and persist the result for idempotent replay. Read-only chat tools cannot make writes.
- Opt-in PDF knowledge: bounded text extraction in a worker, lexical retrieval and file/page citations. Source visibility, tenant, status and checksum are checked again; HR document versions are excluded. File deletion purges derived text. Sharing excerpts with the configured AI provider requires operator awareness, including cloud providers.
- Added recovery CLI `npm run security:resume` for an existing local Docker/OpenBao/Keycloak stack. It uses existing operator material, validates TLS and never initializes a new store or changes credentials/policies.

## Database and compatibility

MySQL 8.0.44, Prisma 6.19.3. One additive migration creates ai_task_drafts, ai_knowledge_documents and ai_knowledge_chunks. The 25 previous migrations are unchanged. Apply with db:migrate:deploy after Prisma generate/validate; do not use db push or reset against an existing database. Back up the database normally before upgrades. Roll back application code before considering removal of new tables; dropping them loses draft/index data.

Local demo office has been configured to HaUI campus 1, 298 Cau Dien, radius 100 m, and missing near-term weekday schedules filled without overwriting existing schedules. This is local data, not a forced location for new installations. New users follow the existing office Google Maps/shift setup in the teacher quickstart.

## Limits

PDF text only: no OCR, at most 5 MB / 30 pages / 100,000 characters and 100 indexed PDFs per organization. Retrieval is bounded lexical search, not semantic/vector search. RAG chat requires a tool-calling provider; legacy OpenAI/Gemini analytics remains available separately. Mock results are explicitly labelled and are not real-provider verification. Cloud model use needs each operator's own Ollama Cloud login; credentials are never included in source.

GPS can be spoofed and a 100 m geofence is not a hardware anti-fraud guarantee. Local security setup is not production deployment: domain/TLS, Keycloak production persistence and independent secret custody/backups remain deployment responsibilities. Academic reports/slides are deliberately outside this technical release.

Source remains Apache-2.0; dependency licenses and notices remain separate. See README and contracts/api for setup and exact API authorization.
